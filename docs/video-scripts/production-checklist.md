# Hawaii Sports Center Video Production Checklist

## AI Tool Recommendation

### Recommended Approach: Screen Recording + AI Voiceover

**Why this approach:**
1. **Authenticity** - Users need to see the actual app interface
2. **Accuracy** - Screen recordings ensure features match script
3. **Flexibility** - Easy to re-record specific sections as app updates
4. **Cost-effective** - ~$17/mo vs $24/mo for avatar tools
5. **Quality** - ElevenLabs voices are nearly indistinguishable from human

### Tools Needed

| Tool | Purpose | Cost | Notes |
|------|---------|------|-------|
| **Loom** or **OBS** | Screen recording | Free | OBS is more powerful, Loom is simpler |
| **ElevenLabs** | AI voiceover | $5/mo (Starter) | Best voice quality, many voice options |
| **Descript** | Video editing | $12/mo (Creator) | Auto-syncs audio, easy callouts |

**Total monthly cost: ~$17**

### Alternative Tools

| Tool | Use Case | Cost |
|------|----------|------|
| **HeyGen** | AI avatar presenter | $24/mo |
| **Synthesia** | Corporate avatar videos | $22/mo |
| **Play.ht** | Alternative voiceover | $31/mo |
| **CapCut** | Free video editing | Free |
| **DaVinci Resolve** | Professional editing | Free |
